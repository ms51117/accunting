# سامانه جامع حسابداری و مدیریت مالی شخصی (Accounting System)

سامانه جامع، مدرن و ریسپانسیو حسابداری، مدیریت اسناد تجاری و تحلیل نقدینگی مبتنی بر **FastAPI**، **SQLAlchemy**، **SQLite**، **تقویم شمسی (Jalali)** و **Chart.js**.

---

## ✨ امکانات و قابلیت‌های برجسته:

- 📊 **داشبورد تحلیلی و هوش مالی:**
  - نمودار تعاملی روند گردش مالی ۶ ماهه (مقایسه ماه به ماه درآمدها، هزینه‌ها و تراز خالص نقدینگی).
  - نمودار دونات (Doughnut) سهم مخارج برحسب سرفصل‌ها با نمایش درصد و مبالغ ریالی.
  - نمایش فوری موجودی نقدینگی، اسناد دریافتنی/پرداختنی و سررسیدهای پیش‌رو.

- 📈 **مرکز گزارش‌گیری و تحلیل پیشرفته (`/reports`):**
  - فیلترهای زمانی جامع (ماه جاری، ۳ ماه اخیر، ۶ ماه اخیر، کل سال جاری، تمام دوران و بازه دلخواه تقویم شمسی).
  - فیلتر بر اساس حساب بانکی، سرفصل دسته‌بندی و نوع تراکنش (درآمد، هزینه، انتقال بین‌بانکی).
  - کارت‌های شاخص عملکرد (KPIs): درآمد کل، هزینه کل، تراز خالص نقدینگی، نرخ پس‌انداز و میانگین هزینه روزانه.
  - ماتریس گردش و مانده حساب‌های بانکی و جدول تفکیک سرفصل‌ها.
  - خروجی اکسل استاندارد (`CSV` همراه با UTF-8 BOM جهت نمایش صحیح حروف و ارقام فارسی در Microsoft Excel).
  - بهینه‌سازی فرمت چاپ رسمی (Print Friendly) برای استخراج PDF.

- 🔔 **یادآور و نوتیفیکیشن هوشمند تلگرام برای چک‌ها:**
  - کارگر پس‌زمینه روزانه جهت بررسی و ارسال خودکار هشدار سررسید به تلگرام.
  - دسته‌بندی چک‌ها (سررسید امروز، فردا، تا ۳ روز آینده و چک‌های معوقه).
  - **تشخیص خودکار کسری موجودی حساب:** هشدار فوری در صورت عدم تکافوی موجودی حساب بانکی برای چک‌های پرداختی.
  - دکمه استعلام و ارسال دستی آنی در صفحه مدیریت چک‌ها.

- 📝 **مدیریت کامل اسناد تجاری و تعهدات:**
  - **چک‌ها و صیادی:** ثبت چک‌های صیادی و عادی، وصول خودکار همراه با کسر/افزایش مانده حساب، برگشت زدن و نشانگرهای هوشمند فوریت سررسید.
  - **دفتر بدهی و مطالبات:** پیگیری اشخاص بدهکار/طلبکار، تسویه مرحله‌ای و دکمه تسویه کامل یک‌کلیکه.
  - **اشخاص و طرف‌حساب‌ها:** دفترچه مشخصات با شماره کارت، شبا و یادداشت.
  - **حساب‌ها و صندوق‌ها:** مدیریت حساب‌های بانکی، کارت‌ها و صندوق‌های نقدینگی.
  - **سرفصل‌ها و دسته‌بندی‌ها:** تعریف دسته‌ها با پالت رنگی و آیکون اختصاصی.

- 📱 **پشتیبانی PWA و حالت آفلاین:**
  - قابلیت نصب به عنوان اپلیکیشن نیتیو روی اندروید، iOS و ویندوز.
  - تم مدرن تاریک (Ultra-Modern Dark UI) با فونت بهینه‌شده **وزیرمتن** و انطباق کامل با نمایشگرهای لمسی موبایل.

- 🛡️ **پشتیبان‌گیری امن و اتصال به دامنه اختصاصی:**
  - دانلود مستقیم بک‌آپ پایگاه‌داده با فرمت استاندارد JSON و ارسال خودکار به ربات تلگرام.
  - پشتیبانی از اتصال مستقیم به دامنه اختصاصی شخصی با SSL و دسترسی امن اینترنتی.

## 🚀 راهنمای استقرار با داکر (Docker & Docker Compose):

این روش سریع‌ترین و امن‌ترین شیوه استقرار روی سرورهای لینوکس (اوبونتو، دبیان، سنت‌او‌اس و...) است. پایگاه داده و فایل‌های بک‌آپ روی سرور Host ماندگار (Persistent) خواهند بود.

### ۱. دریافت پروژه:
```bash
git clone https://github.com/ms51117/accunting.git
cd accunting
```

### ۲. تنظیم متغیرهای محیطی:
```bash
cp .env.example .env
# در صورت تمایل مقادیر TELEGRAM_BOT_TOKEN یا پورت را در .env ویرایش فرمایید:
# nano .env
```

### ۳. اجرای سرویس با داکر:
```bash
docker compose up -d --build
```

### ۴. مشاهده وضعیت و لاگ‌ها:
```bash
docker compose ps
docker compose logs -f
```

سامانه روی پورت `8000` در دسترس خواهد بود:
`http://SERVER_IP:8000` یا از طریق لینک تونل کلودفلر ارسال‌شده به تلگرام شما.

## 💻 راهنمای اجرای محلی (Local Development):

```bash
# ساخت محیط مجازی پایتون
python -m venv .venv
source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate

# نصب وابستگی‌ها
pip install -r requirements.txt

# تنظیم فایل محیطی
cp .env.example .env

# اجرای سرور توسعه
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
